## 간단해진 웹 편집 화면 (2026-10-19)

[document-studio-preview.html](artifacts/document-studio-preview.html)을 다운로드하여 Chrome/Edge에서 여세요. 설치나 서버가 필요 없습니다. 상단 / 왼쪽 도구 / 가운데 문서 / 오른쪽 설정 구조는 유지합니다. 아래 이전 날짜별 항목은 변경 이력이며, 현재 조작 방법은 이 절을 기준으로 합니다.

- **직접 배치:** 블록 위 ‘이동’ 손잡이로 이동하고 가장자리 손잡이로 크기를 바꿉니다. 시작 열·너비·배치 줄·높이 계산·세로 칸 수·배치 화살표·너비 프리셋은 설정 패널에서 제거했습니다. 내용이 넘치면 자동 확장하며 아래 내용도 다시 배치합니다. 텍스트·표·입력 항목의 아래쪽 높이 손잡이를 두 번 클릭하면 내용 높이에 맞춥니다. 명시적 여백과 수동 페이지 나누기는 유지합니다.
- **글자 배치:** 상단 가로 정렬 옆의 ‘세로’ 도구로 위 / 가운데 / 아래를 고릅니다. 텍스트·입력 항목은 블록 안에서, 표는 현재 선택한 셀·행·열·범위에서 적용합니다. 가로 가운데와 세로 가운데를 함께 쓰면 공간의 정중앙에 놓입니다. 숫자 1 / 1.2 / 1.5 등의 줄 간격 드롭다운은 제거했으며 기존 파일의 줄 간격은 보존합니다.
- **저장과 열기 한곳:** 상단 **저장·열기**를 누릅니다. 저장 범위에서 ‘현재 양식 / 문서’ 또는 ‘전체 자료’를 고르고 같은 **저장** 버튼을 누릅니다. 첫 저장에는 이름 창이 뜨고, 이후 저장은 같은 보관함 항목을 갱신합니다. 이미지를 포함한 JSON 파일도 다운로드합니다. 현재 문서 저장은 그 문서의 내장 이미지·글꼴만 담고, 전체 자료는 다른 양식·저장 문서·보관 이미지도 포함합니다. ‘다른 이름으로 저장’은 새 항목을 만듭니다.
- **다시 열기:** 같은 메뉴의 **파일 열기**에서 문서 JSON과 전체 백업 JSON을 모두 엽니다. 전체 백업은 현재 자료와 병합하며 기존 자료를 초기화하지 않습니다. 브라우저 자동 저장이 제한돼도 파일 저장·복원은 동작합니다. JSON 저장은 HTML 파일 자체를 덮어쓰지 않습니다. 다른 PC로 옮길 때는 전체 자료를 선택해 보관하세요.
- **출력:** 상단 **저장 형식**에서 PDF / Word / Excel / PNG / JPG를 고른 다음, 오른쪽 **선택 형식으로 저장**을 누릅니다. 형식을 고르는 것만으로 파일이나 인쇄 창이 열리지 않습니다. 웹의 PDF는 브라우저 인쇄 창에서 ‘PDF로 저장’을 고릅니다. Word/Excel은 편집용 변환이고 원본 배치의 정밀 재현은 PDF/이미지를 이용합니다.

검증 명령: `npm run build`, `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm test -- --workers=2`, `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:preview`. [최종 HTML 검증 기록](artifacts/simple-ui-validation.json), [화면](docs/screenshots/simple-ui-editor.png), [통합 파일 메뉴](docs/screenshots/simple-ui-file-menu.png), [PDF](artifacts/document-studio-simple-ui.pdf)를 제공합니다. 클라우드 브라우저 정책으로 직접 파일 열기는 차단돼 같은 HTML을 네트워크가 끊긴 페이지에 주입하여 검사했습니다. Windows 더블클릭과 실제 인쇄 대화상자는 직접 확인하지 못했습니다.

## 부분 글꼴 축소 후 위젯 높이 수정 (2026-10-19)

글자를 드래그해 작게 만들었는데도 블록 기본 글꼴이 큰 경우 문단의 기본 줄 높이가 남아 위젯을 줄일 수 없던 문제를 수정했습니다. 모든 글자가 개별 크기를 가진 문단은 실제 글꼴 크기로 높이를 계산하며, 큰 글자나 기본 서식을 쓰는 글자가 남으면 해당 글자의 공간을 보존합니다. 계산용 문단 서식은 저장하는 부분 서식과 구분하며 텍스트 선택 범위는 유지합니다.

- 높이 손잡이로 내용이 들어가는 최소 행 수까지 줄일 수 있습니다. 현재 너비에서 내용이 들어가지 않는 높이는 드래그 미리보기에서도 제한하여 드롭 후 갑자기 다시 커지지 않게 했습니다.
- 자동 높이에서는 부분 글꼴 축소도 점유 칸과 아래 내용을 줄입니다. 직접 지정한 최소 높이 모드에서는 손잡이로 줄이거나 ‘내용에 맞춤’을 선택하세요.
- 첨부 상황과 같은 기본 29pt/실제 글자 14pt/8mm 격자 제목을 3행에서 2행으로 축소하고, 12mm 격자에서 실제 글자를 6pt로 바꿔 1행이 되는 흐름을 검사했습니다. 큰 글자가 일부 남아 있는 경우, 실행 취소/다시 실행, 저장·재열기·JSON 복원·미리보기·PDF도 검사했습니다.

검증: `tests/inline-sizing.spec.ts`의 세 시나리오는 수정 전 실패를 재현했고 수정 후 통과했습니다. `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/inline-sizing-preview.mjs`로 최종 HTML을 오프라인 검사합니다. [기록](artifacts/inline-height-validation.json), [축소 후 화면](docs/screenshots/inline-height-after.png), [PDF](artifacts/document-studio-inline-height.pdf)를 제공합니다. 클라우드 브라우저의 직접 파일 열기 제한 때문에 같은 HTML을 오프라인 페이지에 주입했으며 Windows 더블클릭은 직접 검증하지 못했습니다.

## 웹 편집기 격자 재계산 수정 (2026-10-19)

이번 결과물은 웹용 [document-studio-preview.html](artifacts/document-studio-preview.html)입니다. 다운로드하여 Chrome/Edge에서 열며 설치나 서버가 필요 없습니다. 편집 내용은 HTML 자체에 덮어쓰지 않습니다. 기존 내보내기/가져오기와 브라우저 보조 저장을 사용하세요.

- **실제 내용과 격자 높이 분리:** 숨은 측정용 블록에는 이전 점유 높이를 적용하지 않습니다. 실제 글꼴·부분 서식·줄바꿈·표 셀 높이를 측정하고 필요한 정수 행 수로 올림합니다. 줄어든 높이가 이전 측정값 때문에 다시 커지는 현상을 막습니다.
- **행 높이 설정:** 상단 `12열 · 12mm 행` 또는 격자 톱니 버튼 → ‘격자 한 행 높이’. 양식 편집에서 변경하며 본문 블록 높이·아래 위치·자동 페이지를 다시 계산합니다. 글꼴 크기와 명시적인 mm 서명 높이는 유지합니다. 작은 행에 내용이 안 들어가면 여러 행을 사용하며 글자를 자르지 않습니다. 표 내부의 행은 셀 내용과 서식에 따라 높이가 정해지고, 표 블록의 전체 점유 높이가 본문 격자에 맞춰집니다.
- **자동 축소:** 텍스트·표·입력 항목 선택 → 오른쪽 ‘높이 계산 → 내용에 맞춤’. 글자 크기·줄 간격·내용 변경 시 필요한 칸으로 줄고 다음 내용이 올라옵니다. 한 행보다 작게는 줄지 않습니다. 같은 줄은 남은 블록 중 가장 큰 높이를 유지합니다.
- **직접 확보한 크기:** 세로 손잡이나 세로 칸 수를 조절하면 ‘지정한 행 수 이상 확보’로 바뀝니다. 글자가 작아져도 확보한 여백은 보존합니다. ‘내용에 맞춤’으로 돌아가면 다시 자동 축소합니다. 도형·이미지·여백 블록은 지정한 격자 행 수를 유지합니다.
- **이전 자료:** v1 버전과 저장 키는 유지합니다. 선택적 `heightMode` 필드만 추가하며 원본 양식과 문서·이미지를 초기화하지 않습니다. 이전 다중 행 블록은 처음 열었을 때 크기를 보존합니다. 텍스트/표/필드 내용이나 글자 크기를 편집하면 내용에 맞춤으로 전환합니다. 새 버전에서 직접 확보한 최소 높이는 편집해도 보존합니다. 의도적인 줄 사이 여백과 수동 페이지 나누기도 유지합니다.

검증: `tests/grid-reflow.spec.ts`는 글자 축소, 실제 격자 점유 높이, 8/24/8/12mm 반복 변경, 실행 취소/다시 실행, 새로고침 복원, 좌우 배치·여백·수동 페이지 유지, 표 글꼴 축소에 따른 페이지 감소를 검사합니다. 단일 HTML 오프라인 검증 기록은 `artifacts/grid-reflow-validation.json`에 저장합니다. 클라우드 Chromium의 파일 URL 열기는 정책상 차단되어, 파일 자체를 읽어 네트워크가 끊긴 페이지에 주입하여 확인합니다. Windows에서 더블클릭과 실제 인쇄 대화상자는 확인하지 못했습니다.

## Windows EXE 데스크톱 버전 (2026-10-19)

확인용 결과물은 `artifacts/DocumentStudio-1.0.0-win-x64.exe`입니다. 더블클릭으로 실행하며 별도 설치·서버·인터넷이 필요하지 않습니다. [실행·이전·백업·출력 안내](docs/windows-guide.md)에 저장 위치와 복원 방법을 적었습니다. 웹의 기존 JSON을 가져올 수 있습니다.

기존 화면과 편집 기능을 Electron에 연결하고 PC 파일 자동 저장, Windows 파일 창을 통한 JSON 내보내기/가져오기, 직접 PDF 저장을 추가했습니다. **다른 형식 저장**에서 Word(DOCX)·Excel(XLSX)·PNG·JPG를 선택합니다. Excel 수량×단가·합계 수식, Word/Excel의 텍스트·표·내장 이미지, 페이지별 이미지 출력을 지원합니다. Word·Excel은 편집용 변환으로 자유 배치·워터마크·장식·줄바꿈의 정확한 재현에는 제한이 있으며 정확한 배치는 PDF·이미지로 출력합니다. DOCX/XLSX 역가져오기는 미구현입니다.

Linux의 실제 Electron 앱에서 실행·자동 저장·종료 직전 입력·재실행 복원·이미지·JSON·Office·이미지·PDF 출력을 검사했습니다. Windows EXE 자체를 Windows에서 직접 실행하거나 Microsoft Office에서 열어 확인하는 검증은 이 Linux 환경에서 수행하지 못했습니다. 코드 서명이 없는 첫 배포 파일이므로 Windows의 게시자 확인 알림이 나타날 수 있습니다.

개발: `npm ci` → `npm exec -- install-electron` → `npm run desktop`. Windows 파일 생성: `npm run desktop:win`. OS 코드는 `desktop`, 재사용 문서 모델·변환은 `src/core`, 화면은 `src/ui`에 있습니다. 검증 기록과 출력 예시는 `artifacts/desktop`에 제공합니다.

견적서, POD, Agreement 양식을 편집하고 실제 입력값으로 문서를 만드는 웹 첫 버전입니다. 로그인, 계정, 백엔드, 외부 API가 필요하지 않습니다. 웹 버전의 데이터와 이미지는 현재 브라우저에 저장하고, EXE는 PC 앱 데이터 폴더에 저장합니다.

## 단일 HTML 미리보기 — 설치 없이 확인

확인용 결과물: [document-studio-preview.html](artifacts/document-studio-preview.html)

채팅 전달 시에는 닫기(X)가 있는 Codex 일반 HTML Preview를 우선하며 별도 전체화면/고정 패널 전용 결과로 제공하지 않습니다. HTML은 전체화면 API를 호출하지 않습니다. Codex의 바깥쪽 뷰어·닫기 버튼은 클라이언트가 제어하므로 이 프로젝트 코드나 현재 연결 도구에서 창 형태를 강제로 지정할 수는 없습니다.

이 **HTML 파일 하나만 다운로드한 뒤 더블클릭**하거나 Chrome/Edge에서 파일 열기로 선택하세요. CSS, JavaScript와 아이콘을 파일에 포함했습니다. CDN, 인터넷, 별도 이미지 폴더, 외부 파일 fetch, 모듈 로딩, 설치, 명령어, 개발 서버가 필요하지 않습니다. 기존 편집기를 그대로 번들하므로 아래에 설명한 블록 편집·표·이미지·서명·페이지 꾸미기·페이지 넘김·인쇄 기능을 실제로 조작할 수 있습니다.

**HTML 원본 파일은 편집 내용으로 덮어쓰지 않습니다.** 작성 자료와 이미지를 보관하려면 상단 파일 안내줄의 **문서 내보내기**로 JSON 문서 파일을 내려받으세요. 다음에 HTML을 열고 **문서 가져오기**로 해당 JSON을 선택하면 양식·문서·이미지·현재 초안을 복원합니다. 왼쪽 아래의 전체 자료 내보내기 / 백업 가져오기도 같은 기능입니다.

브라우저 자동 저장은 실행 시 읽기·쓰기·재읽기 확인 후 보조적으로 사용합니다. 로컬 파일 저장소가 차단되거나 용량이 부족해도 편집, 이미지 업로드, JSON 내보내기·가져오기는 계속 작동합니다. 이때 양식/문서 저장 버튼은 **현재 화면의 목록에 보관**하며 영구 저장됐다고 표시하지 않습니다. 창을 닫기 전에 JSON을 내보내세요. 파일 위치·브라우저·정책에 따라 자동 저장 공간이 달라지므로 JSON 파일을 기준으로 보관하세요.

직접 파일 열기는 클라우드 관리 브라우저의 `file://` 차단 정책 때문에 이 환경에서 확인할 수 없습니다. 실제 생성된 HTML을 오프라인 브라우저에 그대로 주입하여 외부 파일 요청 없이 조작과 출력, 자동 저장 차단 상태의 내보내기/가져오기를 검사합니다. Windows Chrome/Edge의 직접 파일 열기와 실제 인쇄 대화상자는 추가 확인 대상입니다. 단일 HTML 검사 명령은 개발자용 `npm run test:preview`이며 검증 기록은 `artifacts/preview-validation.json`에 남깁니다.

단일 HTML 검증 결과: 블록 손잡이 이동·너비 조절, 텍스트·서식, 38행 표·열 너비·계산·페이지 분할, PNG 업로드·서명 재사용, 머리글·바닥글, 워터마크, 이미지 포함 JSON 복원이 통과했습니다. 저장소 읽기·쓰기를 차단한 상태에서도 가져오기·편집·내보내기가 통과했습니다. 외부 파일 요청과 JavaScript 오류는 0건이며, HTML 원본이 바뀌지 않음을 확인했습니다. 인쇄 미리보기와 PDF는 A4 3페이지를 유지하며 머리글·바닥글·표 마지막 행·서명 제목이 텍스트로 추출됩니다. 확인용 PDF는 `artifacts/document-studio-preview-check.pdf`입니다.

## 서명 영역 조절과 제목 위치 수정 (2026-10-18)

- 서명 선택 → 오른쪽 **서명 영역 높이**에서 이미지가 들어가는 안쪽 높이를 **10~200mm**로 직접 입력합니다. 격자 모드와 문서 작성에서도 사용할 수 있습니다. 제목·선·위아래 간격은 별도이며 전체 블록은 필요한 격자 행만큼 공간을 확보합니다.

- 문서 작성에서 높이·제목 위치·선 설정을 바꿔도 보관된 원본 양식은 유지됩니다. `signatureHeight`와 `signatureTitlePosition`은 선택적인 v1 확장이므로 기존 자료를 초기화하지 않습니다. 저장·재열기·JSON 내보내기/가져오기·인쇄에도 유지됩니다.

## 입력 항목·문서 작성·페이지 삭제 개선 (2026-10-18)

두 모드는 같은 편집 화면과 코드, 같은 레이아웃 계산을 사용합니다. 별도 프로그램 두 개를 만드는 구조가 아닙니다. 양식은 재사용할 배치·기본값, 문서는 고객별 실제 값과 양식 복사본을 저장하기 위해 구분합니다.

- **양식에서도 바로 입력:** 고객명·작성일·일반 입력 항목·체크박스를 문서 위에서 바로 조작합니다. 양식에서는 기본값, 문서 작성에서는 현재 문서의 실제 값으로 저장합니다. 문서 값을 바꿔도 양식의 기본값과 고유 ID는 유지됩니다.
- **입력 항목과 표:** 입력 항목은 이름과 자료형을 가진 한 개의 값 자리입니다. 표는 여러 행·열로 구성되며 행 반복과 수량×단가·합계를 지원합니다. 이전 `{입력 항목}`은 빈 값의 자리 표시였습니다. 이제 직접 입력하며, 오른쪽 ‘입력 항목 설정’에서 이름·자료형·기본값·필수 여부를 정합니다. ‘항목명 폭’은 mm로 조절하며 0은 자동, 최대 표시 폭은 블록의 70%입니다. 블록 전체 너비는 기존 격자 손잡이로 조절합니다.
- **작성 화면 틀어짐 수정:** 항목명은 입력칸에 밀려 축소되지 않으며, 실제 값의 출력 영역이 모든 모드의 높이를 결정합니다. 입력 컨트롤은 그 영역에 겹쳐 놓아 글꼴·값이 바뀌어도 표를 덮지 않습니다. 큰 글꼴·긴 값·날짜·숫자·체크박스도 검증합니다. 인쇄에는 입력 컨트롤과 필수 표시가 빠지고 실제 값이 출력됩니다.
- **문서에서도 색 변경:** 항목을 선택하고 상단 A로 글자색, 오른쪽 ‘문서 색상 · 배치 정보’에서 블록 배경색을 바꿉니다. 표는 행·열·셀 범위 선택 후 배경색과 글자색을 지정합니다. 반복 행 편집을 막은 표도 셀 서식은 변경할 수 있습니다. 현재 문서 사본에만 반영되며 원본 양식·입력값·표 행/열은 유지됩니다. 검정·회색 팔레트를 추가했습니다. 기본 양식의 남색·옅은 청회색과 앱 화면의 남색/청록 UI는 임의로 바꾸지 않았습니다. 일부 글자에 이미 지정한 부분 색상은 블록 기본색보다 우선합니다.
- **수동 페이지 삭제:** 나누기로 생긴 페이지 위 ‘수동 페이지 나누기 → 삭제 · 앞 페이지와 이어붙이기’를 누르거나 왼쪽 페이지 목록의 휴지통을 누르세요. 양식·문서 양쪽에서 사용할 수 있고 한 번의 실행 취소/다시 실행을 지원합니다. 다음 페이지의 내용은 유지하고 나누기만 제거합니다. 자동으로 넘친 페이지는 본문이 줄어 공간이 생기면 사라집니다. 수동 나누기를 지워도 본문이 한 페이지보다 길면 여러 페이지가 남을 수 있습니다.

`npm run test:field-preview`로 전달 HTML 자체를 오프라인 검사합니다. [검증 기록](artifacts/field-modes-validation.json), [PDF](artifacts/document-studio-fields-check.pdf), [문서 작성 화면](docs/screenshots/fields-writing.png), [페이지 나누기 삭제 화면](docs/screenshots/page-break-delete.png)을 제공합니다. `field.labelWidth`는 선택적인 v1 확장으로 기존 자료를 초기화하지 않습니다. 직접 파일 열기는 클라우드 브라우저 정책으로 차단되어 동일 HTML을 네트워크가 끊긴 페이지에 주입해 검사합니다. 실제 Windows의 더블클릭·날짜 선택창·인쇄 대화상자는 별도 확인 대상입니다.

## 빈자리 자동 정리와 추가 취소 (2026-10-13)

- 새 요소를 끌어오는 동안에는 배치 표시만 보여 줍니다. Esc 또는 문서 밖 드롭은 문서, 저장 데이터, 실행 취소 이력을 바꾸지 않습니다.
- **이미지 추가는 이미지 선택·업로드가 성공한 뒤 확정합니다.** 창 닫기, Esc, 파일 선택 취소, 잘못된 파일에는 빈 블록을 만들지 않습니다. 이미지 생성과 주변 재배치는 한 번의 실행 취소/다시 실행으로 복구합니다.
- 본문은 줄 순서와 나란한 블록 관계를 저장하고 실제 높이로 다시 배치합니다. 삭제·다른 위치로 이동·높이 축소·텍스트 감소·표 행 삭제 후 아래 내용이 자동으로 올라옵니다. 한 줄의 높이는 남은 블록 중 최대 높이입니다. 다른 열에 내용이 남아 있는 행은 메우지 않으며, 엇갈린 배치 안에서도 완전히 빈 행만 닫습니다. 별도의 정리 버튼은 필요하지 않습니다.
- 다음 페이지의 본문도 다시 배치하고 불필요한 자동 페이지를 제거합니다. 표는 한 원본의 행으로 분할하고 머리행을 반복합니다. 서명 영역은 통째로 이동하며 수동 페이지 나누기와 머리글·바닥글 영역은 유지합니다.
- **명시적인 여백:** 왼쪽 ‘여백’을 삽입한 뒤 세로 칸 수로 높이를 정하세요. 사용자가 정한 최소 확보 높이, 구분선 위아래 간격, 기존 줄 사이의 의도적 빈 행도 유지합니다. ‘문서에서 이미지 제거’는 해당 이미지 블록을 삭제하고 아래 공간을 닫습니다. 이미지 보관함의 원본은 남습니다.
- 저장 키와 루트 버전은 기존 v1을 유지하고 `bodyFlow.version = 1`을 추가합니다. 이전 자료를 처음 편집할 때 현재 줄 배치와 간격을 보존해 변환하며, 라이브러리·이미지·양식·문서를 초기화하지 않습니다. 블록의 `row`는 호환용 표시 값이고 자동 여백의 근거로 사용하지 않습니다.

이전 형식에는 빈 행이 생긴 이유가 기록되어 있지 않습니다. 따라서 **이미 저장된 출처 불명의 빈 행은 의도적인 간격일 수 있어 임의로 삭제하지 않습니다.** 새 편집 과정에서 생기는 자동 밀림은 고정 여백으로 저장하지 않으므로 삭제·축소 시 다시 닫힙니다. 직접 지정한 최소 높이는 내용이 줄어도 유지됩니다. 내용에 맞춰 자동으로 줄이려면 ‘높이 계산 → 내용에 맞춤’을 선택하세요.

`npm run test:flow-preview`는 전달할 HTML 자체를 네트워크 없이 실행해 삽입/파일 취소, 삭제와 한 번의 실행 취소/다시 실행, 32행→8행 표 축소와 서명 이동, 여백·수동 나누기 유지, 저장소 제한 상태의 이미지 포함 내보내기/재열기/가져오기, 2페이지 A4 PDF를 확인합니다. 기록: [flow-validation.json](artifacts/flow-validation.json), [확인 PDF](artifacts/document-studio-flow-check.pdf), [화면 캡처](docs/screenshots/flow-editor.png). 실제 Windows 파일 선택창의 취소 버튼과 파일 더블클릭·인쇄 창은 추가 확인 대상입니다. 파일 취소는 Chromium의 `cancel` 이벤트 경로로 검사했습니다.

상단 / 왼쪽 도구 / 가운데 A4 / 오른쪽 설정 구조를 유지합니다. 최신 확인 파일은 위의 `document-studio-preview.html`이며 개발 서버 없이 사용합니다.

- **격자:** 옅은 청회색의 얇은 점선입니다. 표시와 맞춤은 별도 버튼이고 톱니 버튼에서 진하기를 바꿉니다. 맞춤을 끄면 블록을 칸 사이의 세부 위치로 이동할 수 있습니다. 너비·확보 높이는 위젯 칸 단위를 유지하고, 겹치지 않도록 주변 공간을 확보합니다. 편집 격자·선택 테두리·손잡이는 미리보기와 인쇄에서 제거합니다.
- **부분 서식:** 텍스트 블록과 일반 표 셀에서 글자를 드래그한 뒤 글꼴·크기·굵게·기울임·밑줄·글자색·형광펜·서식 지우기를 적용합니다. 색상 버튼은 선택을 유지하는 팔레트를 엽니다. 커서만 있으면 이후 입력 서식, 이동 손잡이 등으로 블록을 선택하면 기본 서식에 적용합니다. 정렬·줄 간격은 선택 문단에 적용합니다. 혼합 서식 표시와 Ctrl+B/I/U, 앱 실행 취소·다시 실행을 지원합니다.
- **표 선택:** 행의 ▸, 열의 ▾, 표 전체 ▦ 손잡이를 사용합니다. 오른쪽 ‘셀 범위 선택’에서 드래그하거나 Shift+클릭하면 직사각형 범위를 선택합니다. 글자 편집으로 돌아가면 셀 안에서도 부분 서식이 가능합니다. 선택 범위의 배경·글자색·글자 서식·가로/세로 정렬·여백·테두리 색/굵기/종류/변을 변경합니다. 머리행 색과 합계 행 굵게는 빠른 적용 버튼을 제공합니다. 공유 테두리는 마지막으로 지정한 선을 표시하며 주변 셀의 저장된 배경·글자 서식은 바꾸지 않습니다. 계산 금액 셀은 자동 계산값을 유지하며 셀 단위 서식은 적용할 수 있습니다.
- **글꼴:** 검색, 기본 계열, 시스템 글꼴 불러오기, 이름 직접 입력, 글꼴 파일 불러오기를 제공합니다. `queryLocalFonts` 지원 및 보안 환경을 확인하고, 사용자가 버튼을 누를 때만 API를 호출합니다. 거부·미지원·파일 정책 제한 때는 안내 후 계속 편집할 수 있습니다. 이름 입력 시 사용을 확인하지 못한 글꼴은 대체 가능 안내를 표시합니다. 선택 글꼴에 없는 문자도 대체 글꼴을 사용합니다.
- **글꼴 파일 유지:** TTF/OTF/WOFF/WOFF2를 브라우저 `FontFace`로 해석합니다. 파일당 2MB, 문서당 20개까지 포함하며 지원하지 않거나 손상된 파일은 거부합니다. 파일 데이터와 고유 글꼴 이름을 문서에 저장하므로 브라우저 복원·양식/문서 복사·이미지 포함 JSON 내보내기/가져오기에서 유지합니다. HTML 원본에 업로드 내용을 기록하는 방식은 아닙니다. 시스템 글꼴은 이름만 저장하므로 다른 PC에서 대체될 수 있습니다. 파일 글꼴도 브라우저 저장 용량을 사용합니다.
- **도장·서명:** 왼쪽 버튼을 눌렀을 때만 보관함을 엽니다. 문서 작성에서 서명 자리를 선택하거나 문서의 첫 서명 자리로 삽입합니다. 업로드·선택 후 삽입하면 패널을 닫고, 이미지의 크기·위치·잠금을 오른쪽에서 설정합니다. 닫기·Esc, 이름 변경과 보관함 삭제를 지원합니다. 기본 샘플 이미지를 저장하지 않습니다. 양식에는 자리만 저장하고 서명 이미지는 작성 문서에 포함합니다.
- **저장:** 상단 현재 이름을 눌러 변경합니다. 첫 ‘저장’에는 이름 창이 열리고 이후 같은 항목을 업데이트합니다. 보조 메뉴의 ‘다른 이름으로 저장’은 새 항목입니다. ‘양식 보관함’은 이름 검색·종류 분류·썸네일·수정일·양식 편집/이 양식으로 작성·복제/이름 변경/삭제를 제공합니다. 문서 작성에서 원본 양식을 덮어쓰지 않습니다. 열기/가져오기만으로 수정일을 변경하지 않습니다. 저장소가 제한되면 ‘파일로 보관’ 안내에 따라 JSON을 내보내세요.
- **이미지:** 전체 표시/영역 채우기 자르기와 자르기 위치를 설정합니다. 원본 이미지 데이터와 비율은 유지합니다. 위치·너비는 접을 수 있는 격자 설정과 이동/크기 손잡이에서 조절합니다.

**기존 자료 호환:** 저장 키 `document-studio.v1`과 버전 1을 유지하며 `rich` 글자 구간, 표 `richCells`/`cellStyles`, `fonts` 등을 선택 필드로 추가했습니다. 기존 문자열 문서와 양식은 서식 구간 없이 그대로 읽습니다. 저장값을 초기화하지 않습니다. 새 형식은 최신 HTML에서 여세요. HTML 파일 위치나 브라우저를 바꾸면 자동 저장 공간이 달라질 수 있으니 이전 HTML에서 JSON을 내보내 최신 HTML로 가져오세요.

**검증 자료:** `tests/enhancements.spec.ts`가 단어 서식/팔레트 선택 유지, 셀 범위/개별 서식, 문단/커서 입력, 저장 UI, 글꼴 실패/파일 복원, 서명 패널, 맞춤 해제, 긴 서식 본문/반복 표, 행·열 삭제를 검사합니다. `npm run test:enhanced-preview`는 실제 단일 HTML을 오프라인으로 로드하고 글꼴·서식·서명 포함 JSON 재복원 및 PDF 텍스트 추출을 확인합니다. 실행 기록은 `artifacts/enhanced-validation.json`, 화면은 `docs/screenshots/enhanced-editor.png`, 확인 PDF는 `artifacts/document-studio-enhanced-check.pdf`입니다. 클라우드 관리 정책으로 직접 `file://` 열기는 차단되어 동일 HTML을 오프라인 페이지에 주입하는 방식으로 검사합니다. Windows의 실제 파일 더블클릭·시스템 글꼴 권한 승인·한국어 IME·인쇄 대화상자는 추가 확인 대상입니다. 실제 글꼴 파일 검증은 TTF를 사용했습니다. OTF/WOFF/WOFF2는 입력·해석 경로를 제공하지만 이번 검증에 각 형식의 실제 파일을 사용하지 않았습니다.

## 개발 소스 실행 (선택)

Node.js 22.12 이상이 필요합니다. 이 저장소는 Node.js 24.19.0에서 검증했습니다.

```bash
npm ci
npm run dev
```

개발 화면 주소: `http://localhost:5173`

클라우드에서 실행한 개발 서버의 localhost는 해당 클라우드 머신을 가리킵니다. 사용자 PC에서는 저장소를 내려받아 위 명령을 실행하세요. 이 주소는 공개 배포 주소가 아닙니다.

### 폴더형 빌드 (선택)

```bash
npm run build
```

빌드는 `dist` 폴더형 결과물과 `artifacts/document-studio-preview.html` 단일 파일을 함께 생성합니다. 확인용 단일 HTML에는 모든 실행 코드를 포함하므로 `assets` 폴더를 함께 옮길 필요가 없습니다. 폴더형 결과물을 선택하는 경우에만 `dist/index.html`과 `assets` 폴더를 함께 유지하세요.

클라우드 Chromium은 관리 정책으로 `file://` 접근을 금지하여 직접 파일 열기는 이 환경에서 검증하지 못했습니다. 대신 실제 네트워크를 끈 상태에서 빌드 파일만 전달하여 실행·서식·입력·저장·새로고침을 검증하는 `test:offline`을 제공합니다. Windows의 Chrome/Edge에서 직접 파일을 여는 검증은 후속 확인 대상입니다.

로컬 파일 저장 공간 지원은 브라우저와 정책에 따라 다릅니다. 자동 저장을 사용할 수 없다는 안내가 표시되면 JSON 파일로 내보내기/가져오기를 사용하세요. 개발 서버로 전환할 필요는 없습니다.

## 사용 방법

1. 문서 종류를 고르거나 왼쪽 아래 **빈 양식 만들기**를 누릅니다.
2. **양식 편집**에서 왼쪽의 텍스트·표·이미지·입력 항목·구분선·서명 영역 등을 추가합니다.
3. 내용을 클릭해 편집합니다. 블록을 선택하면 이동 손잡이, 너비 조절 손잡이와 관련 설정이 나타납니다.
4. 오른쪽 **시작 열**, **너비**, **배치 줄**로 정확한 배치를 설정할 수 있습니다. 같은 줄에서 빈 열에 놓으면 나란히 배치됩니다. 충돌하면 다음 줄로 이동합니다.
5. 양식 이름을 정하고 **저장**을 누릅니다. 저장 목록에서 다시 열거나 복제할 수 있습니다.
6. **문서 작성**을 누르면 양식의 독립 복사본을 만듭니다. 입력 항목, 허용된 반복 표 행, 서명 이미지를 작성한 뒤 **저장**을 누릅니다.
7. **미리보기 → PDF 출력**에서 브라우저 인쇄 창의 **PDF로 저장**을 선택합니다.

**양식 편집으로 돌아갈 때:** 작성 중인 문서에서 새 양식 복사본을 만듭니다. 기존 저장 양식을 수정하려면 저장 목록에서 해당 양식을 직접 여세요. 문서 종류 변경 및 빈 양식 만들기는 새 초안을 시작하며, 실행 취소로 이전 초안에 돌아갈 수 있습니다.

## 위젯처럼 배치하기

새 양식은 **12열 × 세로 격자**로 시작합니다. 행 높이는 기본 12mm이며 페이지 설정에서 바꿀 수 있습니다. 격자 표시를 켜면 옅은 모눈종이 선과 칸 번호가 보입니다. 번갈아 칠한 열 배경은 제거했습니다. 블록은 시작 열·배치 줄·가로 칸 수·세로 칸 수를 갖습니다. `3열 × 4행`, `5열 × 3행`처럼 서로 다른 크기의 사각형을 놓고, 짧은 블록 아래의 빈 칸에도 다른 블록을 배치할 수 있습니다.

- **원하는 곳에 추가:** 빈 격자 칸을 클릭한 뒤 왼쪽 요소 버튼을 누르거나, 요소 버튼을 문서로 직접 끌어 놓으세요. 왼쪽 **새 요소 삽입 위치**에서 선택 요소 위·아래·왼쪽·오른쪽, 문서 맨 위·맨 아래도 지정할 수 있습니다. 선택 요소 옆의 공간이 없으면 먼저 너비를 줄이세요.
- **이동:** 블록을 선택하면 위쪽에 큰 **이동** 손잡이가 나타납니다. 손잡이를 잡아 격자 칸으로 드래그하면 배치 크기의 미리보기가 보입니다. 내용을 클릭하는 것은 편집입니다. 이동 중 `Esc`로 취소할 수 있습니다.
- **크기 조절:** 좌우 가장자리는 가로 칸, 위아래 가장자리는 세로 칸, 네 모서리는 두 방향을 함께 조절합니다. 오른쪽의 **너비 / 세로 칸 수**로 숫자를 입력해도 됩니다.
- **서명 오른쪽에 놓기:** 서명 영역 선택 → **절반** → **오른쪽** → 세로 칸 수를 `3`으로 설정하면 `6열 × 3행` 영역이 오른쪽에 놓입니다. 삽입 위치를 **선택 요소 왼쪽**으로 바꾸면 같은 높이의 왼쪽 공간에 다른 블록을 추가할 수 있습니다.
- **미세 조절:** 오른쪽에 3열·절반·전체 너비, 왼쪽·가운데·오른쪽 배치, 한 칸씩 이동하는 버튼을 제공합니다. 배치 정렬과 글자 정렬은 서로 독립적입니다.

**표의 칸 너비:** 양식 편집에서 표를 선택한 뒤 셀 사이 세로 경계선의 ↔ 손잡이를 좌우로 끌어 조절하세요. 양옆 두 열의 너비가 바뀌며 표 전체 너비는 유지됩니다. 확대·축소 상태에서도 같은 방식으로 조절하며, `Esc`로 취소하거나 실행 취소로 되돌릴 수 있습니다. 다음 페이지의 같은 표에도 변경된 열 너비가 적용됩니다. 손잡이에 키보드 초점을 둔 뒤 방향키로도 조절할 수 있습니다. 숫자 입력은 오른쪽 **열 역할 · 너비 세부 설정**을 펼칠 때만 보이는 보조 기능입니다. 행 높이는 내용에 따라 자동으로 늘어나며, 행 높이 경계선 드래그는 이번 변경 범위에 포함하지 않습니다.

텍스트·표·입력 항목은 **높이 계산 → 내용에 맞춤**에서 실제 내용으로 점유 행을 계산합니다. 글자 크기·줄 간격·내용을 줄이면 블록과 아래 내용도 줄어듭니다. 세로 손잡이나 ‘세로 칸 수’를 직접 조절하면 **지정한 행 수 이상 확보**로 전환하여 최소 높이를 보존합니다. 어느 방식이든 내용이 길어지면 필요한 행만큼 자동으로 늘어나고 아래 블록을 밀어냅니다. 내용을 자르거나 본문 블록끼리 겹치게 하지 않습니다. 사용자가 직접 남겨 둔 빈 행은 배치의 일부로 유지됩니다. 큰 표는 여전히 행 단위로 여러 페이지에 이어지며, 원본 표 데이터는 하나입니다.

이전 버전에서 저장한 문서·양식은 자동 변환하지 않습니다. 양식 편집에서 상단 **위젯 격자로 전환**을 누르면 새 조절 방식을 사용할 수 있고, 실행 취소로 이전 배치에 돌아갈 수 있습니다. 저장된 문서는 해당 문서의 배치 규칙을 계속 사용합니다. 새 위젯 배치를 포함한 JSON은 업데이트된 미리보기에서 여세요.

- 텍스트, 표, 이미지, 자료형별 입력 항목, 체크박스, 이모티콘, 사각형·타원, 얇은 구분선, 서명 영역, 수동 페이지 나누기.
- 글꼴 계열, 글자 크기, 굵게·기울임·밑줄, 색상, 정렬, 블록 배경색.
- 표 셀 입력, 마지막 행·열 추가/삭제, **표 내부 세로 경계선 드래그로 열 너비 조절**, 수량×단가, 합계, 반복 행 설정. 숫자의 쉼표를 허용합니다. 프로그램 코드 실행이나 `eval`을 사용하지 않습니다.
- 머리글·바닥글 높이(mm 또는 경계선 드래그), 반복 장식, 첫 페이지 동일/다르게/숨김, 텍스트·이미지·도형 자유 배치, 페이지 번호.
- 워터마크 추가·교체·삭제, 표시, 너비·위치, 전체/지정 페이지, 투명도. **0%는 완전히 보임, 100%는 완전히 투명**입니다. 본문 클릭을 가로채지 않습니다.
- PNG/JPEG 보관함, 이름 수정, 재사용, 투명 PNG 유지, 서명 영역 내 이동·너비·비율 유지·위치 잠금. 이미지 하나당 최대 3MB입니다.
- 실제 DOM 높이로 계산하는 자동 페이지 증가·정리, 텍스트 분할, 표 행 단위 분할, 머리행·열 너비 반복, 제목과 다음 내용 함께 유지.
- 서명 영역은 항상 전체를 함께 이동합니다. 한 페이지보다 큰 표 행이나 원자적 요소는 안내와 함께 축소하여 무한 페이지 생성을 방지합니다.
- 세로 연속 보기 / 두 페이지 나란히 보기, 페이지 이동, 기본 너비 맞춤, 확대·축소, 패널 너비 조절·접기. 작은 화면에서는 패널을 접어 편집 영역을 확보합니다.
- 양식·문서·이미지 로컬 저장, 입력 중 자동 저장, 새로고침 복원, 버전이 있는 JSON 백업.
- 화면과 같은 문서 데이터·배치 규칙을 사용하는 A4 브라우저 인쇄. 패널·격자·선택·손잡이를 제외하며 텍스트와 표를 실제 HTML로 출력합니다.

문서 작성 모드에서는 양식의 구조와 고정 문구가 보호됩니다. 서명 삽입은 이미지 배치 기능이며 인증된 전자서명이 아닙니다. 양식 저장 시 실제 서명 이미지는 제외하고 서명 자리만 보관합니다.

## 저장과 백업

현재 편집 초안은 변경 후 약 0.5초에 자동 저장합니다. **저장 목록에 보관하려면 상단 저장 버튼을 눌러야 합니다.** 상단 저장 버튼의 결과와 하단 자동 저장 표시를 확인하세요. 저장값을 다시 읽어 일치할 때만 저장 성공으로 표시합니다.

- 저장 키: `document-studio.v1` (`localStorage`), 데이터 버전: `1`.
- 양식, 저장 문서, 이미지 자산, 현재 초안을 별도로 관리합니다. 문서는 양식 배치의 복사본과 실제 입력값을 갖습니다.
- 배치된 이미지는 문서 안에 원본 데이터 URL로 포함됩니다. 보관함에서 삭제해도 저장 문서의 이미지가 깨지지 않습니다.
- 브라우저 저장 용량은 보통 수 MB 수준입니다. 동일 이미지의 문서별 복사본도 용량을 사용합니다. 큰 이미지나 많은 문서가 있으면 **저장 실패**가 표시될 수 있습니다.
- 저장 실패 시 **JSON 백업**부터 내려받고 큰 이미지·불필요한 저장 항목을 정리한 다음 **저장 재시도**를 누르세요. 실패를 저장됨으로 표시하지 않습니다.
- 왼쪽 아래 **전체 자료 내보내기**로 양식·문서·이미지·현재 초안을 모두 포함한 JSON을 내려받습니다.
- 다른 PC에서는 **백업 가져오기**로 복원합니다. 기존 목록에 자료를 합치며, **같은 ID는 가져온 백업으로 갱신**하고 현재 초안도 백업의 초안으로 전환합니다. 가져오기 전 현재 자료를 먼저 내보내는 것이 좋습니다.
- 지원하지 않는 버전·잘못된 구조의 백업은 거부합니다. JSON 백업은 최대 40MB입니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 사이트 주소·포트·파일 위치 변경에 주의하세요. 중요한 문서는 정기적으로 JSON과 PDF를 별도 보관하세요.

필수 항목 미입력 시 저장 후 초안 안내를 표시하며 작성 중 문서도 보관할 수 있습니다. 고유 ID는 항목 복제 시 새로 생성됩니다.

## 출력

인쇄 창에서 용지는 **A4**, 배율 **100%**, 여백 **없음**, 브라우저 머리글·바닥글 **끔**, 배경 그래픽 **켬**으로 설정합니다. 앱 머리글·바닥글은 별도로 문서에 포함되어 있습니다. 프린터 드라이버의 강제 여백이나 브라우저별 글꼴 차이는 최종 출력에 영향을 줄 수 있습니다.

문서 전체를 스크린샷으로 출력하지 않습니다. 텍스트·표는 검색 가능한 PDF 텍스트로 유지하고, 업로드한 이미지는 원본 이미지로 출력합니다. 다른 OS의 대체 글꼴에서 줄 높이가 달라질 수 있으므로 해당 브라우저에서 최종 페이지를 확인하세요.

## 이번 버전의 제한 및 다음 단계

- 고급 셀 병합, 임의 수식, 배경 자동 제거, 인증 전자서명은 미구현입니다. 관련 기능을 작동하는 버튼처럼 노출하지 않습니다.
- 임의의 고급 문단 레이아웃, 목록/들여쓰기, 셀 병합은 후속 기능입니다. 기본 부분 서식·정렬·줄 간격은 지원합니다.
- 표 삭제는 마지막 행·열부터 지원합니다. 특정 행 삽입/삭제, 셀 병합, 행별 문서 작성 권한은 후속 개선입니다.
- 너무 큰 단일 표 행은 축소 안내를 표시합니다. 복잡한 한 행을 여러 페이지로 분할하는 고급 편집은 후속 기능입니다.
- 장식은 지정된 머리글·바닥글 높이 안에서만 표시됩니다. 장식 텍스트가 많으면 높이를 늘리거나 글자 크기를 줄이세요.
- 저장 용량과 다중 탭 충돌 처리 개선을 위해 다음 단계에서는 IndexedDB와 파일 백업 어댑터를 검토합니다. 현재 같은 주소를 여러 탭에서 동시에 편집하면 마지막 저장이 반영됩니다.
- Windows에서 EXE 직접 실행·한국어 입력·실제 인쇄·Microsoft Office 호환을 추가 검증하고, 코드 서명과 설치형 패키징을 진행할 수 있습니다.
