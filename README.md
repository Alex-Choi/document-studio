# 문서 스튜디오 Windows 다운로드

[Windows 64비트 ZIP 다운로드](https://github.com/Alex-Choi/document-studio/raw/refs/heads/windows-download-v1.0.0/DocumentStudio-1.0.0-win-x64.zip?download=1)

ZIP 압축을 풀고 DocumentStudio-1.0.0-win-x64.exe를 더블클릭하세요. 설치·명령어·서버가 필요하지 않습니다. 사용법.txt가 함께 들어 있습니다.

Windows 10/11 64비트용 첫 버전입니다. 기존 HTML 자료는 JSON으로 내보낸 뒤 EXE에서 가져옵니다. PDF·Word·Excel·PNG·JPG 저장을 지원합니다. Word·Excel은 편집용 변환이라 배치 차이가 생길 수 있습니다.

Linux Electron에서 실행·저장·출력을 검사했으며 Windows 직접 실행과 실제 Microsoft Office에서 열기는 미검증입니다. 코드 서명이 없어 Windows에서 게시자 확인 알림이 표시될 수 있습니다.
